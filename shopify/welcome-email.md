# Welcome email (Shopify Email automation)

Sent automatically to everyone who signs up: the welcome pop-up, the footer sign-up,
and the "Opening soon" page. Footer and Opening-soon sign-ups never see the pop-up's
code, so this email is how they get it.

## Set it up in Shopify

1. Shopify admin > **Marketing** > **Automations** > **Create automation**.
2. Pick the **Welcome new subscribers** template (it may be called "Welcome new
   subscriber" or "Welcome with discount"). Install **Shopify Email** if it asks.
3. Open the email step and paste the subject, preview text, and body below.
   - For the code, use the discount block and choose **WELCOME15** (already
     created by the setup script), or type the code as text.
   - Point the button to `/collections/kits`.
4. Click **Turn on automation**.
